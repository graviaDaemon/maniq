# Contributing

Maniq is in pre-alpha and is built by one person as a learning project. For now, contributing means **feedback**.

## Feedback: open an issue

Feedback is very welcome, through [issues](../../issues/new/choose). Useful things to share:

- syntax that is confusing, inconsistent or surprising (point at a file in `samples/` or a rule in the grammar);
- design decisions you'd question, and why;
- bugs in the compiler: what you ran, what you expected, what happened;
- links to languages, papers or compilers that solve something better.

One topic per issue keeps the discussion easy to follow.

## Pull requests and forks

**Pull requests are not accepted until Maniq reaches alpha.** PRs opened before then are closed automatically. If you
have a change in mind, describe it in an issue instead.

GitHub lets anyone fork a public repository, but the code is not licensed for reuse yet (see [LICENSE](LICENSE)).
Forks are welcome for reading and experimenting. Once Maniq reaches alpha, it gets an open-source license and pull
requests open up.
